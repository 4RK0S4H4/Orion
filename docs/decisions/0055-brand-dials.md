# 0055: Brand dials: an app can make Orion its own (2026-11-16)

**Status:** decided by the owner in the Design Review quiz ([`explore/design-review.html`](../../explore/design-review.html));
the first dials are built. The owner added: "I'll let you decide the order of what to build first", and deferred to the
recommendation on every answer. The recommendation agrees with all eight.

## The question
The owner wants Orion to "look great as is" and also be "super customized as a base to really make it unique per app".
The review found an app could change only its color: corners followed tokens halfway, and nothing covered typefaces
or the temperature of the grays.

## The answers
| Question | Answer |
|---|---|
| How far may an app move from stock Orion | **Brand dials**: a short list of checked presets; not "everything open" |
| Corners per app | **Soft range**: one dial from pills down to about 10, never sharp, still concentric |
| Typeface per app | **The app picks both** a display face and a text face |
| Letter spacing | **Tuned for Inter** (Material's values were made for Roboto) |
| Hierarchy in neutral mode | **Both**: stronger type by default, and a page tone an app can turn on |
| Website kit | **Build it** |
| What comes first | **Tidy, then brand dials** |
| Who Orion is for | **Only the owner, through the skill**: no package, no typed API |

## The rule
Orion has two layers of identity.

**Fixed (this is Orion, in every app):** filled, never outlined; no shadows; glass only on what floats, with the
contrast floor; concentric corners; the ten motion patterns; the placement ladder, pages, states and undo; Title Case
labels; things you click are rounder than things you type into; every text and control proven for contrast.

**The brand dials (one app's own):** each is an attribute on `<html>`, set and saved by `S4.theme({ … })`. Only tokens
change, so no component has rules for them and no app restyles a component to get them.

| Dial | `S4.theme` key | Values | Default |
|---|---|---|---|
| Accent | `seed`, `variant` | any color (0045) | mono |
| Color mode | `surfaces` | `neutral`, `tinted` (0052) | neutral |
| Gray temperature | `gray` | `pure`, `warm`, `cool` | pure |
| Page tone | `page` | `plain`, `soft` (white cards on a soft gray page; light mode) | plain |
| Corners | `corners` | `round` (pills), `soft` (14), `firm` (10); or `--s4-shape-control` of 10px or more | round |
| Display face | `display` | `inter`, `serif`, `rounded`, `mono`, `system`, or a font-family | inter |
| Text face | `text` | the same | inter |
| Density | `data-density` | comfortable, compact, auto (0043) | comfortable |
| Icon set | `S4.icon.use` | Solar, Phosphor, Phosphor Bold | Solar |

This amends 0023 to 0025 in one way only: "small things are pills" becomes "small things are pills unless the app
turns the corners dial"; nothing is ever sharp, and nothing is outlined. It amends the Inter rule: Inter is the
default face, not the only one.

## Also decided and built
- **Letter spacing is tuned for Inter**: slightly negative at text sizes, tighter as size grows (`typography.tokens.json`).
  Any other face drops it and starts from its own spacing.
- **Stronger type**: display, headline and title-large are weight 600 (emphasized 700). Stat values follow.

## How it is built
- `--s4-shape-control`: the corner of everything you click. Buttons, icon buttons, chips, status pills, menu items,
  navigation rows and indicators, tabs, pagination, breadcrumbs, FABs and tooltips read it, clamped to half their
  height, so the default is still an exact pill and the press morph still works.
- `components/base/brand.css` (hand-written): the corner, typeface and page-tone presets.
- `components/base/gray.css` (generated by `scripts/build-gray.mjs`): warm and cool grays made from the pure ones at
  the same luminance. `npm run check:gray` fails if any color drifts by more than 1% as a contrast ratio sees it, so
  the 83 proven pairs hold. White stays white and black stays black. High contrast keeps the pure grays.
- The showcase's Settings has a "Make It Yours" pane with every dial.
