Layers

Layers let a 42-key board do the work of a full-size one. Hold a thumb key and every other key changes meaning; let go and it changes back.

Mallet 3.2Updated 9 November 2026Edit This Page on GitHub

How Layers Stack

Mallet keeps layers in a stack, with base at the bottom. When you hold a layer key, its layer goes on top. A key that the top layer leaves empty falls through to the layer below, so you only define what changes.

  • Hold a layer key to use it for as long as you hold it. This is what most people want.
  • Tap a layer key twice quickly to lock the layer on. Tap once more to drop it.
  • Hold Lower and Raise together to reach a fourth layer, adjust, for settings and the bootloader.

Up to 16 Layers

Most people use three or four. Every layer costs 84 bytes of flash per half, so even small controllers have room.

Define a Layer

Layers live in mallet.toml, next to your board’s name. Write the keys in rows the way they sit on the board; __ means “fall through to the layer below”.

[board]
name = "corne-v4"

[layers.lower]
hold = "left_thumb_middle"
keys = """
  esc  1   2   3   4   5      6   7    8    9    0   bspc
  __   f1  f2  f3  f4  f5     left down up  right home end
  __   f6  f7  f8  f9  f10    pgdn pgup vold volu mute __
                 __  __  __     __  __  __
"""

Flash It

Plug in the left half, then run the flasher. It checks the file, builds the firmware and waits for the board to enter its bootloader.

brew install mallet
mallet flash mallet.toml --side left
curl -fsSL https://get.mallet.example | sh
sudo mallet udev install   # once, so you can flash without sudo
mallet flash mallet.toml --side left
winget install Mallet.Mallet
mallet flash mallet.toml --side left

Unplug the Cable Between the Halves

Flash one half at a time, with the TRRS cable out. Plugging it in while powered can short the controller on some boards.

Repeat with --side right for the other half. Both halves must run the same version, or the right half will refuse to pair and blink twice.

If a Layer Won’t Stay On

Check that the layer key is a hold, not a toggle, and that nothing above it in the stack uses the same key. mallet check mallet.toml prints every key that two layers both claim.
