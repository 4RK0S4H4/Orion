Components / Themes On Any Container

Every brand dial and the light or dark mode can sit on any element, not only on <html>. The nearest one wins, so themes nest: a dark sidebar in a light app, a light card in a dark app, a branded band, two brands side by side. Contrast, reduced motion and reduced transparency stay page-wide and reach inside. Try the Theme and Contrast controls above: every example follows.

A Dark Rail in a Light App

data-theme="dark" on the rail. It takes the dark surfaces, text, glass and native controls (color-scheme); the page beside it stays in the app's mode. With the page in dark mode, the rail stays dark.

From Script

S4.theme(options, element) takes the same keys as the page-wide call (mode, seed, variant, surfaces, gray, page, corners, display, text) and writes them as attributes on that element. Nothing is saved. null lets the element follow the page again; a default value ('round', 'pure', 'inter') brings stock Orion back inside a branded page.

S4.theme({ mode: null }, card)

Attributes

data-theme="light | dark"              the mode inside (sets color-scheme too)
data-accent="blue | #0b57d0"           a scoped accent (data-accent-variant, data-surfaces="tinted")
data-gray="warm | cool | pure"         gray temperature inside
data-page="soft"                       a soft page inside (light mode only)
data-corners="round | soft | firm"     corners inside
data-type-display="inter | serif | rounded | mono | system"
data-type-text="inter | serif | rounded | mono | system"
data-density="comfortable | compact | auto"
data-energy="calm | standard | lively"   motion energy inside

App defaults (base/defaults.css)
data-buttons="filled | tonal"    data-cards="elevated | filled"
data-lists="segmented"           data-rail="auto | expanded | collapsed"
