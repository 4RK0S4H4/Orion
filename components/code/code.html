Components / Code

A block of code with its file name and language, line numbers, marked lines, a Wrap toggle and Copy. The colors are fixed syntax tokens proven at 4.5:1 on every surface, in light, dark and both high-contrast modes, and on every tinted scheme, so code reads the same with any accent. A tiny built-in tokenizer colors JavaScript, TypeScript, JSON, CSS, HTML, Python and shell; anything else arrives already split into s4-syntax-* spans.

File, Language, Line Numbers, Marked Lines

The scroller takes focus, so long lines can be read with the arrow keys. Marked lines get a step-up fill and an accent bar at their start.

Languages

Each block is one language. Comments are italic as well as gray, so they never rely on color.

Wrap

Long lines scroll sideways by default. data-wrap (or the Wrap button) wraps them instead; line numbers stay with their first row.

Diff

Added and removed lines keep their sign in its own column and are real <ins> and <del> elements, so the change is never told by color alone.

No Head, Pre-Tokenised

Without a head the buttons sit in the top corner. Code from another highlighter keeps its spans when they use the s4-syntax-* names.

Inline Code and Keys

In running text: S4.table(el).setRows(rows) fills a table. Keys are .s4-kbd; a combination sits in .s4-keys.

Find a record: CtrlK Edit the cell: Enter, cancel: Esc
