Components / Document Tabs

The open documents of a desktop window. Each tab is a thing you opened: it closes (the button, a middle-click, ), keeps a dot while it has unsaved changes, and moves (drag it, , or Move Left and Move Right in its right-click menu). When they no longer fit, All Tabs lists them. Not the content tabs: those switch between fixed views of one thing and never close.

A Row Of Open Files

Left and Right walk the tabs, Delete closes one, opens the last closed tab again; New File adds one. In a browser some of these keys belong to the browser; in an installed app they all work.
