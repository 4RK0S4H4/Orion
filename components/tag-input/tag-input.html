Components / Tag Input

Several values in one field. Each chosen value is a chip inside the box and the cursor sits after them; the box grows a line at a time and keeps its corners. Type to pick from suggestions or to make a new one, paste a list separated by commas, remove a chip with its button or with Backspace in the empty field.

Pick and Create

Suggestions from a <template>; data-create lets people add their own (Enter or a comma). data-max shows a counter and stops at the limit. Try pasting Rent, Car, Health; Gifts.

Up to five.
Only people in your workspace.

Many Values

The chips wrap onto more lines; the box’s corners stay the same and the label and supporting text stay where they are.

Anything you would like to be asked about.
