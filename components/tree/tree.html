Components / Tree View

Nested things you open and close: folders and files, chapters and scenes, regions and sites. Rows are small list rows: a filled selection, a hover that leans in from where the pointer came, corners from the dial. Use the arrow keys (Right opens, Left closes), Home and End, or type a name. F2 renames.

Files, Comfortable And Compact

The same tree at touch size (48 rows, for a phone's file browser) and in compact density (28 rows, a desktop sidebar). Counts sit at the end; the guide lines show whose child a row is.
