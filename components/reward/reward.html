Components / Small Rewards

The small moments that make finishing something feel good. Each one is an existing motion pattern, so fun never looks like a different app. Under reduced motion they simply show their end state.

A Check That Draws Itself

For a thing that is done: paid, sent, saved, complete.

A Number That Counts To Its Value

For a total that just changed or a stat arriving on screen. It counts once; the real value is what a screen reader hears.

A Row That Settles

After a drag, the row lands where it belongs on the calm morph. See Direct Manipulation.
