Components / Filters and Views

One pattern for narrowing a collection: a search that filters as you type, the filters in force as chips (each removable, and Clear All), Add Filter, a tool panel with every facet and what each choice would give, a sort control and named views you can save, rename and delete (with Undo). The panel is a tool panel (decision 0054): from 600 wide the page stays live beside it and every choice acts at once. The state is in the address, so a view can be linked.

Filter Bar, Views and a Table

Where It Goes

The views sit on top (they change everything below), the bar under them, the filters in force under the bar, then the count and the collection. On a phone the views and the chips are one row each that scrolls sideways, the search takes the full width and the panel covers the screen with a Show button that closes it. A saved view is a named set of filters, a search and a sort; the first view is the whole collection and cannot be deleted.
