Components / Menu Bar

The application menu inside the window: File, Edit, View and the rest, for Windows and Linux and for web apps in a window. Every item is a command (S4.commands), so the same list feeds the shortcuts, right-click menus and the palette. On a Mac shell that draws the native menu bar, <html data-native-menu> hides it; on a phone it is not shown.

In A Title Bar

Press F10 (or Alt alone) to move to the bar, the arrow keys to walk it, Alt with a letter to open a menu. With one menu open, point at another to switch. Open Recent and Line Spacing are submenus; Word Wrap and Show Ruler are check items; the zoom items are a radio group; Paste is off until something is copied.
