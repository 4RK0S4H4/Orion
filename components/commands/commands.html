Components / Commands

One list of what an app can do, written once with S4.commands.add, and every way of doing it drawn from that list: the menu bar, menus, right-click menus, keyboard shortcuts, the command palette (), buttons with data-cmd, and a desktop shell's native menu. A command knows its label, icon, shortcut, whether it can run now and whether it is on, so every place shows the same thing.

Four Places, One Command

Pin is a check command, Archive is off until a row is picked. Try the buttons, a row's right-click menu, the palette or : they all run the same thing and stay in step.

The Same Menu For A Shell

S4.commands.native('row') gives the menu as plain data with Electron-style accelerators, for a desktop shell to draw its own native menu from. It is rebuilt here whenever a command changes (s4-commands).
