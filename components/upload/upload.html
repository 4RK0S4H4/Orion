Components / File Upload

A drop zone that is also a button, so it works with a tap, a click, the keyboard or a drag. Each file gets a row with its size, a progress bar while it is sent, Try Again after an error, and Remove. Orion never uploads anything itself: it checks each file, shows it and fires events; the app sends it and reports progress back.

Drop Zone and Files

The hint under the title comes from accept, data-max-size and data-max-files. Here the pretend server takes a few seconds; a file with “fail” in its name fails, and Try Again sends it again. A file that is too big or the wrong type is refused with the reason.
