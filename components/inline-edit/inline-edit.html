Components / Inline Edit

A value you change where it is. It reads as plain text and is a real input underneath, so your own tap puts the cursor in it; pointing at it shows a pencil. Enter or leaving saves, Escape puts it back, and a snackbar offers Undo. No Edit button, no dialog, no Save.

Values in Place

It takes the type of what is around it: a heading stays a heading. Clear a required value and leave: it is kept, with a short message.
