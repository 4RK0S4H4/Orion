Components / Password Field

Helpers for the text field when it holds a password: a Show Password button, a strength meter that says in words how strong it is, and a notice when Caps Lock is on. The form’s own rules decide what is accepted; the meter only helps.

Sign In and Sign Up

Type in the new password to see the meter. Show Password is a toggle (aria-pressed); its name stays the same. Press Caps Lock while typing to see the notice.

At least 12 characters. A few words work well.

Every Strength, Error and Disabled

Case matters.
Only the owner can see it.
