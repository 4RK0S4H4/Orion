Components / Tabs

Tabs move between different panels of content within one screen: a bill's Details, Payments and Notes. They belong with the nav bar and the nav rail: no tray, the labels sit on the surface, and the selected tab gets the same neutral indicator the nav bar and rail use, which slides from tab to tab. Primary tabs sit under the top app bar and organize the whole screen; secondary tabs sit inside a pane or card and divide it further. Use the arrow keys, Home and End: the selection follows focus.

Tabs or a button group? If it swaps what is on the screen, it is tabs. If it changes a value or how the same thing is shown (Week / Month / Year on a chart, list or grid), it is a button group. If it narrows a collection and there can be many, it is chips.
