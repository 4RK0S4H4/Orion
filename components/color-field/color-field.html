Components / Color Field

A swatch and its hex code in one field. Tap the swatch for a small glass panel with the named accents and a hue slider, or type a code. Made for “pick your accent” settings: with data-theme-seed it themes the page as you choose.

Fields

The first field themes this page. The second keeps its own value (a label color for a project) with its own accents from a <template>.

Used for buttons, selection and focus.
Shown beside the project’s name.

Error, Disabled and Compact

A code that isn’t a color is an error when you leave the field.
