What To Build Next

Eight ideas for making Orion work for any app and feel good to use. Each has a small sketch of what it would be (real Orion parts, not final design). Tap an answer under each one, then copy your answers at the end. This page is also the first quiz in the new look: everything here is live Orion.

1. Command Palette

Search everything and run any action from one box, opened with a shortcut. The desktop counterpart of the nav bar.

2. Resizable Panes

Drag the edge between a list and its detail to resize; double-click to collapse. The width is remembered. Try the grip.

Every list, table and pane gets a designed empty, loading, error and offline state, so an app never shows a blank box.

4. Forms That Behave

Errors appear when you leave a field, never while you type. Changes save by themselves with a quiet “Saved” mark. Undo instead of “Are you sure?”. Type in the field, then tap outside it.

5. Small Rewards

A check that draws itself, a number that counts to its value, a row that settles after a drag. Each uses an existing motion pattern, so fun never breaks consistency.
