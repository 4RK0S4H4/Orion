# Demo

`demo/index.html` is **Orion Showcase**, a generic mobile app (Home, Controls, Forms, Settings) that shows every Orion component, built only from the skill
(`skill/orion/`) and its assets. Findings from reviewing it against the skill are in
[`docs/decisions/0005-phase-6-review.md`](../docs/decisions/0005-phase-6-review.md). Published at
https://4rk0s4h4.github.io/Orion/demo/. The `orion.*`, `icons.js`, `m3color.js` and font files here are copies of
`skill/orion/assets/`; refresh them after each build.
